A web application for **Biology**. Designed for high performance, clean architecture, and easy local or cloud deployment.

## 🌟 Tech Stack & Features
- **Backend**: PHP / MySQL Database Engine
- **Frontend**: HTML5 / CSS3 / JavaScript
- **Database Schema**: Exported database schema file included (`database.sql`).
- **Responsive Layout**: Works across Desktop, Tablet, and Mobile devices.

## 🛠️ Quick Installation Guide
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shetesfa/Biology.git
   ```
2. **Setup Database**:
   - Open **phpMyAdmin** (`http://localhost/phpmyadmin`).
   - Import the included `database.sql` file.
3. **Launch Application**:
   - Access via browser: `http://localhost/Biology/`
