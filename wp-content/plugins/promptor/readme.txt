= Privacy and Data Handling =

**OpenAI API:**
When using your own API key, user queries and selected content are sent to OpenAI to generate responses. During the free trial, queries are routed through a Promptor-managed proxy that uses OpenAI on your behalf. Review OpenAI's [Terms of Use](https://openai.com/policies/terms-of-use) and [Privacy Policy](https://openai.com/policies/privacy-policy).

**Telemetry (Optional):**
The free version includes optional anonymous telemetry to help improve the plugin. It is disabled by default and requires explicit opt-in. When enabled, only aggregate statistics are collected (setup progress, KB counts, query totals). No personally identifiable information is ever collected. See our [Privacy Policy](https://promptorai.com/privacy/).

== Installation ==

= Automatic Installation (Recommended) =

1. Go to Plugins > Add New in your WordPress dashboard
2. Search for "Promptor"
3. Click "Install Now" then "Activate"
4. Follow the setup wizard — choose "Try instantly" for the free trial or enter your OpenAI API key

= Manual Installation =

1. Download the plugin .zip file from WordPress.org
2. Go to Plugins > Add New > Upload Plugin
3. Choose the .zip file and click "Install Now"
4. Activate and follow the setup wizard

= First-Time Setup =

1. Activate the plugin — the setup wizard opens automatically
2. Choose "Try Promptor instantly" (no API key) or enter your OpenAI API key
3. Select pages to train the AI on
4. Add `[promptor_search]` to any page or post
5. Start chatting with your AI assistant

== Frequently Asked Questions ==

= Do I need an OpenAI API key to use Promptor? =

No. You can start immediately with the free trial — 10 AI queries, no API key required. The trial lets you select up to 2 pages, train the AI, and test it with your own content. When you're ready for unlimited use, add your own OpenAI API key in Settings.

= What happens after the free trial? =

After 10 queries, the trial ends. Add your OpenAI API key to continue using Promptor with no query limits. Your settings and content selections are preserved.

= Does the AI use my website content or generic responses? =

Promptor reads and uses your actual pages and posts. During trial, selected pages are used to generate real answers. With your API key, the full knowledge base is indexed for more accurate responses.

= How much does the OpenAI API cost? =

OpenAI charges based on usage. A typical conversation costs $0.01-$0.10 depending on length and model. Promptor includes AI Cost Guardrails to help you set spending limits and control costs.

= How do I display the chat on my site? =

Use the shortcode `[promptor_search]` on any page or post. Pro also includes a floating popup widget that appears on all pages.

= Does this work with my WordPress theme? =

Yes. Promptor works with any standard WordPress theme including Astra, Kadence, GeneratePress, Neve, and default themes. CSS isolation prevents style conflicts.

= How many leads can I capture? =

Unlimited in both free and Pro versions. Lead capture has no restrictions.

= What's the difference between Free and Pro? =

Free includes AI chat, lead capture, the no-API-key trial, and up to 3 knowledge base items. Pro removes limits and adds WooCommerce integration, analytics, automation, and white-label branding.

= What languages does Promptor support? =

The AI automatically responds in the visitor's language. Admin interface text supports standard WordPress translations (.po/.mo files).

= Can Promptor replace a contact form? =

Yes. Many sites use Promptor as a conversational alternative to traditional forms. Visitors ask questions, get instant answers, and share their contact details naturally — resulting in higher engagement and more qualified leads.

= Why does the free version have telemetry? =

Telemetry is optional, disabled by default, and only collects anonymous aggregate statistics. It helps us understand which features matter most so we can improve the plugin. You can enable or disable it anytime in Settings > Telemetry.

== External Services ==

This plugin connects to external services to provide its functionality.

**1. OpenAI API**

* **Purpose:** Generate AI chat responses and semantic embeddings
* **Data Sent:** User queries, selected page content, API key (when using your own key)
* **When:** Every chat interaction and knowledge base sync
* **Terms:** [OpenAI Terms of Use](https://openai.com/policies/terms-of-use)
* **Privacy:** [OpenAI Privacy Policy](https://openai.com/policies/privacy-policy)

**2. Promptor Trial Service (Free Trial Only)**

* **Purpose:** Provide AI responses during the free trial without requiring an API key
* **Data Sent:** User queries and selected page content (routed through a managed proxy)
* **When:** During trial chat interactions only
* **Privacy:** [Promptor Privacy Policy](https://promptorai.com/privacy/)

**3. Promptor Telemetry API (Optional, Disabled by Default)**

* **Purpose:** Collect anonymous usage statistics to improve the free version
* **Data Sent:** Setup status, KB counts, query/lead totals (numbers only), plugin/WP/PHP versions, anonymous UUID
* **Data NOT Sent:** Site URLs, IP addresses, emails, content, queries, or any PII
* **When:** Twice daily via WP-Cron, only when explicitly enabled
* **Control:** Enable/disable anytime in Settings > Telemetry
* **Privacy:** [Promptor Privacy Policy](https://promptorai.com/privacy/)
